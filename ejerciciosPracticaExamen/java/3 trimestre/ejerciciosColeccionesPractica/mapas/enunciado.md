Enunciado: Directorio de Empleados
Deberás implementar un programa que permita gestionar el directorio de empleados de una empresa mediante un Mapa. Este directorio relacionará el DNI del empleado (como clave única) con su Nombre completo (como valor). Cada DNI solo podrá aparecer una vez en el directorio.
Las operaciones que debe realizar este programa a través de un menú son:  Dar de alta empleado: Permitirá añadir un nuevo DNI junto con el nombre del empleado. Si el DNI ya existe en el sistema, deberá mostrarse un aviso indicando que el empleado ya está registrado.  Buscar por DNI exacto: Buscará el DNI que introduzca el usuario. Si no existe, mostrará un aviso; si existe, mostrará el nombre del empleado correspondiente.  Buscar empleados por nombre: Deberá mostrar todos los DNIs y Nombres de aquellos empleados cuyo nombre empiece por una cadena de texto indicada por el usuario. Si nadie coincide, se mostrará un aviso.  PDFModificar nombre: Permitirá actualizar el nombre de un empleado a partir de su DNI. Si el DNI introducido no existe, se mostrará un error.
